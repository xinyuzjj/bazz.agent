## 🎯 不是又一个聊天框

AI 助手都在**说话**，BAZZ.AGENT 在**做事**——但你必须先批准。

这不是套在币安 API 上的聊天皮肤，而是一个跑在你币安账号里的**Agent 操作系统**：

- 它读的是 Agent OS 暴露的**真实行情**；
- 直接驱动**四大原生能力**（MCP / 钱包 / x402 / Skill Hub）；
- 每个敏感动作（下单 / 转账 / 签名支付）都会往聊天里丢一张 `Confirm` 卡片——**你点了才执行**，用的是你的真实密钥 / 无密钥 MPC 钱包。

驾驶舱是 Hermes 风格三栏**交易台**：

```
┌──────────────┬─────────────────────────────┬──────────────────┐
│  左栏         │  中栏                        │  右栏             │
│  会话         │  Agent 对话                  │  实时信号         │
│  人格         │  · SSE/NDJSON 流式           │  行情雷达         │
│  工具         │  · 工具实时卡片               │  持仓             │
│  文件         │  · Confirm 确认卡            │  账户             │
└──────────────┴─────────────────────────────┴──────────────────┘
      深色 ⇄ 浅色主题 · 中文 ⇄ EN —— 顶栏一键切换，重启不忘
```

## 🔁 核心闭环

```
   📡 扫描 ──► 🧠 分析 ──► 💡 提案 ──► ✅ 确认 ──► ⚡ 执行
      ▲                                            │
      └────────────── 回到扫描 ◄────────────────────┘
```

> 关键在 **✅ 确认**：每笔订单 / 转账 / 签名支付都等你在聊天里亲手点头。

## ⚡ 快速开始

### 方式一 · Windows 一键下载（推荐）

<div align="center">

**[⬇ 下载最新 setup.exe](https://github.com/xinyuzjj/bazz.agent/releases/latest)** —— 安装即用，无需 Python / Node。

`setup.exe` · `delta-<版本>.zip`（应用内更新自动消费）· `SHA256SUMS` · `MANIFEST.json`

</div>

- 首次启动有约 3–5 秒启动动画给后端热身，然后舱门打开。
- 数据在 `<安装目录>\workspace`（安装盘只读时自动回退 `%APPDATA%\BAZZ.AGENT\workspace`）。
- 无边框窗口：顶栏拖动；右上 `─ / □ / ✕`；**关闭可缩托盘**，后台任务不死。
- 应用内更新：版本守卫 + 增量包 + SHA256 校验，装完自动重启。

> 适用于 Windows 10/11 x64。macOS / Linux 走源码。

### 方式二 · 源码运行（任意系统）

```bash
# 1) 后端 — Python 3.11+
python -m venv .venv && .venv\Scripts\activate    # Windows
# source .venv/bin/activate                        # macOS / Linux
pip install -r requirements.txt

# 2) 前端 — React 构建
cd frontend && npm install && npm run build && cd ..

# 3) 运行（后端直接托管前端构建产物）
.venv\Scripts\python -m uvicorn desktop_app:app --host 127.0.0.1 --port 8080
# → http://127.0.0.1:8080
```

> 行情雷达**不需要任何 Key**。设置里填任意 OpenAI 兼容 `base_url` + Key（DeepSeek / OpenAI / Moonshot / Ollama / 自建）。规则引擎兜底意味着**断网主流程也能跑**。

### 桌面开发模式（Windows）

```bash
start-desktop.bat     # Electron 壳 + .venv 后端，双击即用
start-dev.bat         # FastAPI + Vite 热更新，改 UI 用
```

<details>
<summary><b>🔒 安全模型</b> <i>（点击展开）</i></summary>

- 每笔真实交易 / 转账 / 签名支付都带 `needs_approval`；后端只在显式 `confirm: true` 时放行。
- 密钥从不落盘明文；CEX 密钥每次会话在 UI 输入，你连接授权后才镜像进本地 `binance-cli` profile。
- Agent 永远接触不到原始私钥——Agentic Wallet 是无密钥的。
- `run_command` 白名单：`baw` / `node` / `python` / `git` + 只读 wrapper——任意 shell 直接拒绝；破坏性命令硬拦截。
- 本地 API 在桌面壳运行时启用每次启动随机的 token 鉴权；路径严格设防：不许越界、不许删工作区根、二进制文件标记展示而不是吐乱码。
- 技能防路径穿越；广场发文本地台账留底；UI 里密钥打码。
- 更新包安装前 SHA256 校验 + 版本守卫；先备份 workspace，备份失败即中止更新。

</details>
