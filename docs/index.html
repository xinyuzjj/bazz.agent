§ 能力四块原生能力

不是聊天皮肤套 Binance API —— 四块全部按官方真实协议实现。

MCP Server core

agent.binance.com · Streamable HTTP · OAuth 2.0 PKCE

Binance 官方 Agentic MCP 接入。运行时工具发现，无硬编码工具名；公开行情免鉴权，账户 / 交易走 OAuth + 最小权限 scope。

  • RFC 9728 资源元数据挑战 → PKCE(S256) 浏览器流
  • 工具运行时 tools/list 发现
  • 无提现 scope；Agentic 子账户与主账户隔离

Agentic Wallet baw

npm i -g @binance/agentic-wallet

官方 MPC 无密钥钱包，多链（BSC / ETH / Base / SOL），浏览器扫码登录。Agent 只能经 run_command 白名单调 baw，从不见私钥。

  • 兑换 $50k / DeFi $100k / x402 $20 每日上限
  • 市价单 / 限价单 / 兑换 / 报价
  • 全部 --json 机器可读

x402 / B402 pay

/papi/v2/b402/{supported,verify,settle}

机器对机器支付：卖家 402 → 买家 Agentic Wallet 离线 Permit2 EIP-712 签名 → Facilitator 验证 → 链上点对点结算（Facilitator 代付 gas）。

  • BNB Smart Chain（eip155:56）；真实 /supported 拉配置
  • 签名环节无 gas，体验顺滑
  • 无权限时优雅降级演示

Skill Hub 19 skills

npx skills add <github path>

19 个官方 Binance skill（CEX + Web3 + 自研富媒体发文），意图驱动：对话里表达意图，skill 自己决定调哪个底层 API / CLI。

  • 本地已装 .agents/skills/*，锁文件 skills-lock.json
  • install / run / remove 全套，带路径穿越防护
  • 插件扩展：plugins/<id>/{main.py,plugin.json}

§ 快速开始本地从源码运行

Python 3.11+ · Node 18+ · 一条命令起服务。

  1. 克隆：git clone https://github.com/xinyuzjj/bazz.agent.git
  2. 后端：python -m venv .venv && .venv\Scripts\activate && pip install -r requirements.txt
  3. 前端：cd frontend && npm install && npm run build && cd ..
  4. 启动：.venv\Scripts\python -m uvicorn desktop_app:app --host 127.0.0.1 --port 8080
  5. 打开：http://127.0.0.1:8080

公开行情扫描与基础分析无需任何凭据。
接真实交易 / LLM / MCP / Agentic Wallet 时，分别在「设置」「MCP」「钱包」面板按引导填写或扫码。
